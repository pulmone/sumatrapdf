# PulmOne PDF Viewer

A modified fork of [SumatraPDF](https://www.sumatrapdfreader.org/free-pdf-reader) for use within PulmOne applications.

SumatraPDF is a multi-format (PDF, EPUB, MOBI, CBZ, CBR, FB2, CHM, XPS, DjVu) reader for Windows.

More information on the upstream project:
* [Website](https://www.sumatrapdfreader.org/free-pdf-reader)
* [Manual](https://www.sumatrapdfreader.org/manual/)
* [Developer information](https://www.sumatrapdfreader.org/docs/Contribute-to-SumatraPDF)

## Changes from upstream

- VS2026 compatibility fixes
- Removed command palette (security)
- Removed "Open in ..." options (security)
- Removed Sumatra PDF title branding
